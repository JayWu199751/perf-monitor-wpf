# 12: 设置窗生命周期与退出清理

**What to build:** 设置窗按需打开、关闭后不占用长期资源；应用退出或系统注销时干净关闭窗口、后台任务和原生资源。

**Blocked by:** 07: 指标设置、持久化与性能条布局；11: 共享菜单、托盘主题与透明显示。

**Status:** ready-for-agent

- [ ] 设置窗按需创建；点关闭只隐藏，不退出主应用。
- [ ] 隐藏闲置 5 分钟后释放设置窗实例；重新打开可取消待执行的释放并复用当前实例。
- [ ] 设置窗按内容和当前屏幕工作区决定尺寸；短屏可滚动访问所有行。
- [ ] 从退出命令、注销或关机结束时放行窗口关闭，停止后台工作并释放窗口、托盘及 native 资源。
- [ ] 退出后无遗留 GPU 子进程、幽灵图标、计时器回调或无法退出的隐藏窗口。
