# 05: 物理网卡网速

**What to build:** 用户看到的上下行速度尽量反映真实物理链路，并避免把 TUN、Hyper-V 等重复接口累加成虚高流量。

**Blocked by:** 04: CPU 与内存指标。

**Status:** ready-for-agent

- [ ] 仅将处于 Up 状态且非 loopback 的接口作为基础候选；优先使用 PhysicalMediumType 不为 Unspecified 的物理接口，无物理候选时回退到基础候选。
- [ ] 每轮选择收发速率之和最大的一行作为上下行来源；不得累加子接口，也不得分别挑选上下行最大值。
- [ ] 使用单调时钟实测采样间隔计算字节每秒，再按 1024² 换算并显示一位小数；下行和上行来自同一接口。
- [ ] 首轮、无基线或非正间隔显示 0；计数回退只将该方向本轮置 0；读取失败显示 --。
- [ ] 快速刷新频率与 CPU/内存一致；筛选变化不丢弃有效的接口基线。
