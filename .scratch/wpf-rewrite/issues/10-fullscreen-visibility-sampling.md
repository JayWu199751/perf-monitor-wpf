# 10: 全屏自动隐藏与采样暂停

**What to build:** 全屏应用出现时性能条自动隐藏，退出全屏后按用户的手动选择恢复；隐藏期间暂停指标采样以减少资源占用。

**Blocked by:** 02: 原生性能条窗口交互与 DPI；04: CPU 与内存指标；05: 物理网卡网速；06: GPU 与 ACPI 温度；07: 指标设置、持久化与性能条布局。

**Status:** ready-for-agent

- [ ] 设置提供默认开启的全屏自动隐藏选项；识别无边框 F11 全屏，最大化普通窗口不算全屏，并排除应用自身、桌面和任务栏。
- [ ] 仅在进入/退出全屏的状态边沿处理显隐；手动隐藏优先，用户在同一全屏周期内手动显示后保持显示。
- [ ] 关闭自动隐藏时，仅恢复当前因自动原因隐藏的性能条；手动隐藏状态仍保持隐藏。
- [ ] 性能条隐藏时暂停快慢指标采样；全屏观察继续运行，显示时立即补采样。暂停后的首次网络采样建立新基线。
- [ ] 时钟按自身节奏更新；退出时停止全屏观察和采样任务，不遗留后台投递。
