# 04: CPU 与内存指标

**What to build:** 用户能在性能条中看到及时更新的全机 CPU 使用率和内存使用率，读取失败时能区分缺失与真实的零值。

**Blocked by:** 01: 应用启动壳与托盘入口。

**Status:** ready-for-agent

- [ ] CPU 使用率由全机累计时间差分得到，首次基线为 0，结果为 0–100 整数；读取失败为缺失。
- [ ] 内存百分比使用原始物理字节计算，界面显示整数；快照保留已用和总量 GiB。
- [ ] CPU 和内存读取不阻塞界面；快速刷新可选 1000/2000/5000ms、默认 1000ms，同一通道采样不重叠。
- [ ] 重启或停止采样后，较早的在途结果不能覆盖新结果或投递到已退出的界面。
- [ ] 百分比采用与旧版一致的 Math.round 中点语义；缺失数据显示为 --，不伪装为 0。
