# 02: 原生性能条窗口交互与 DPI

**What to build:** 性能条作为原生 WPF 悬浮窗口，在不同缩放比例下可见、可命中并可顺畅拖动。

**Blocked by:** 01: 应用启动壳与托盘入口。

**Status:** ready-for-agent

- [ ] 窗口采用无标题栏的透明宿主，不产生任务栏按钮，并保持在其他普通窗口上方。
- [ ] 用户从性能条可见内容或透明留白区域拖动时，整窗跟手移动；透明区域的命中与拖动行为在真实 WPF 窗口中验证。
- [ ] 窗口在目标 DPI 和混合 DPI 显示器上保持正确尺寸、命中区域与位置；验证记录覆盖拖动、透明区域和缩放切换。
- [ ] 性能条右键可打开基础菜单，不会同时启动拖动；在透明留白处右键也保留菜单交互。
