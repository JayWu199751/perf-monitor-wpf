# 03: Release 提权与跨权限单实例

**What to build:** Release 在需要时尝试以管理员权限运行温度读取，同时保证拒绝提权仍可使用，普通与管理员启动不会形成多个实例。

**Blocked by:** 01: 应用启动壳与托盘入口。

**Status:** ready-for-agent

- [ ] Debug 始终普通权限启动且不弹 UAC；Release 使用 asInvoker，未提权时每次启动最多自动尝试一次 runas，同一次启动不重试。
- [ ] 用户拒绝或启动提权进程失败后，当前普通权限实例继续运行，CPU 温度显示缺失；已提权启动不再请求提权。
- [ ] 普通与管理员权限的重复启动都能通知现有实例显示性能条，然后让新实例退出，不留下双实例。
- [ ] 以真实令牌状态判断是否提权；验证普通到管理员、管理员到普通、取消 UAC 和启动失败路径，不依赖用户组推断权限。
