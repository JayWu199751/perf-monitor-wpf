# 13: 开机自启与新旧状态隔离

**What to build:** 用户可从新版设置管理当前用户登录时的静默自启；新版与旧版配置及启动项并存时互不修改对方状态。

**Blocked by:** 03: Release 提权与跨权限单实例；07: 指标设置、持久化与性能条布局。

**Status:** ready-for-agent

- [ ] 设置中的自启状态对应当前用户登录触发的最高权限计划任务，路径和带空格参数正确转义，启动为静默 GUI。
- [ ] 创建或删除任务后查询系统实际状态并回写；失败时设置界面不显示成功。
- [ ] Debug 不创建或修改系统自启；新版只创建、查询和删除自己拥有的任务。
- [ ] 新版使用独立的用户级配置目录和自启任务名；同一用户的普通/管理员进程读写同一新版配置。
- [ ] 不读取、导入、迁移、改写或删除旧版配置，不扫描、迁移或删除旧版计划任务与 Run 项；旧版继续可用。
