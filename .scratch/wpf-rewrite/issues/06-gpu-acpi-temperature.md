# 06: GPU 与 ACPI 温度

**What to build:** 用户可看到 NVIDIA GPU 使用率、显存和温度，以及系统可用时的 ACPI 温度；任何单项不可用都不会伪造读数或中断其他指标。

**Blocked by:** 03: Release 提权与跨权限单实例；04: CPU 与内存指标。

**Status:** ready-for-agent

- [ ] NVIDIA 指标沿用约定的 nvidia-smi 字段口径，以无控制台异步方式读取并设置 5 秒超时；多卡时采用首条有效设备记录。
- [ ] 非 NVIDIA、命令不存在、超时、非法输出或读取失败时，GPU 相关值显示 --，CPU、内存和网络仍继续更新。
- [ ] CPU 温度从 ACPI 热区读取并转换为摄氏整数；它代表 ACPI 热区值，不承诺等于核心温度。
- [ ] 非管理员、无热区、访问被拒或查询失败时温度显示 --；多热区沿用最大有效值口径。
- [ ] GPU 与温度慢速刷新可选 3000/5000ms、默认 3000ms；读取不阻塞界面，失败只影响相应指标。
