# 07: 指标设置、持久化与性能条布局

**What to build:** 用户可配置显示哪些指标以及性能条外观和刷新速度；更改立即反映在单行性能条中，并在重启后保留。

**Blocked by:** 02: 原生性能条窗口交互与 DPI；04: CPU 与内存指标；05: 物理网卡网速；06: GPU 与 ACPI 温度。

**Status:** ready-for-agent

- [ ] 设置提供 CPU、内存、GPU、网络和时间五项开关；默认全开，GPU 标注“仅 NVIDIA”。
- [ ] 设置提供快刷新 1000/2000/5000ms（默认 1000ms）和慢刷新 3000/5000ms（默认 3000ms）。
- [ ] 设置提供 system/dark/light 主题、背景不透明度 0.20–1.00（步长 0.05，默认 0.72）和字号 10–18 DIP（默认 12）。
- [ ] 设置更改立即应用、持久化并显示约两秒“已保存”；数值范围校验、损坏配置备份并恢复默认，文件更新具备原子性。
- [ ] 性能条按 CPU、内存、GPU、网络、时间顺序显示可见段；相邻可见段之间才显示分隔线。
- [ ] 字体和布局遵循规格的间距、等宽数字、缺失值和宽度变化规则；数字刷新不造成窗口反复缩放。
