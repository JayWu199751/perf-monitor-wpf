# 移除性能条指标图标

Status: resolved
Progress: accepted

## 用户目标

用户于 2026-10-09 要求删除设置中的「显示图标」功能，不需要显示图标，保持极简；显式使用 grill-with-docs 进行范围澄清与文档记录。

## 已核实的事实

- 「指标图标」指 CPU、内存、GPU、网络、时间五个段的图形标识，不包含文字标签、读数、单位或网络上下行箭头；应用图标与托盘图标有各自的领域定义。
- 实施前设置窗包含「显示图标」分组和五个独立开关；配置模型、局部更新、视图模型和 XAML 均支持这些偏好。
- 原显隐功能规格位于 `.scratch/metric-icon-visibility/spec.md`，本次需求将取代其中的可选图标行为。
- ADR 0006 要求宽度跟随内容自然宽，下限保留 64 DIP 命中区，行内居中时按实际宽度重新居中；移除图标继续遵循此规则。
- 当前工作区已有主占用百分比与时间同色的未提交修改，实施须保留该结果。

## 已确认的范围

用户于 2026-10-09 回复「按你推荐的」，确认整体采用以下范围并实施：

1. 删除设置窗「显示图标」整个分组和五个开关。
2. 从性能条永久移除五个指标图标及其专属间距；不保留隐藏入口或可恢复的图标偏好。
3. 保留 CPU、内存、GPU、显存、网络文字标签、读数、单位、网络上下行箭头和时间读数；「显示指标」继续控制整个段。
4. 保留应用图标、托盘图标、现有主题及主占用百分比颜色行为。
5. 删除对应图标设置、更新接口与无用图形资源；旧配置的 `metricIcons` 字段忽略，正常保存后不再写出，其他设置完整保留。
6. 小窗按移除图标后的内容收缩，沿用最小命中区、贴边与任务栏行内居中规则。

## 验收

- 设置窗初次打开、隐藏后重开和实例重建均无「显示图标」分组及五个开关。
- 新配置及旧配置，无论原图标偏好为开或关，性能条都无指标图标及其占位。
- 有效旧配置含 `metricIcons` 时不因该字段重置其他设置或产生损坏备份；保存后不再输出该字段。
- 标签、读数、单位、网络上下行箭头、时间及整段显隐保持正常；不改变采样与刷新率。
- 深浅主题及不同字号的实际 WPF 布局无图标占位、无裁切，满足自然宽和最小命中区规则。
- 构建与相关自动化检查通过；真实桌面、贴边及行内居中未执行的验收单独记录。

## 文档处理

- 在原图标显隐规格中追加替代说明，保留历史讨论和验收证据。
- 词汇表仅表达领域术语；性能条改为文字呈现，移除已废弃的指标图标条目。
- 本次是可逆的局部功能删除，无需新增 ADR；沿用 ADR 0006。
