# 界面 UI 参数与交互规格

## 1. 规格范围

本文描述性能小窗、设置页和系统托盘菜单的现有界面基线，供设计、重做或替换技术实现时遵循。规格限定在用户可见内容、可调选项、视觉参数、布局及交互行为；不规定程序结构、技术框架、数据采集方式或内部实现。

本文所有尺寸均为界面逻辑像素，除非另有说明；不等同于显示器的物理像素。颜色中的透明度用 RGBA alpha 表示。

## 2. 界面组成

产品包含三个相互配合的界面：

1. **性能小窗**：桌面上的无标题栏横向状态卡片，显示选定的性能指标和本地时间。
2. **设置页**：固定宽度的独立页面，按“显示指标、刷新率、外观、行为”分组。
3. **系统托盘菜单**：提供小窗显隐、打开设置、两项显示行为开关和退出。

小窗始终保持单行布局。关闭设置页只收起设置页；应用继续驻留托盘。退出应用通过托盘或小窗右键菜单中的“退出”操作完成。

## 3. 用户可调选项

### 3.1 设置页

| 分组 | 选项 | 可选值 | 默认值 | 可见效果 |
| --- | --- | --- | --- | --- |
| 显示指标 | CPU 使用率 | 开 / 关 | 开 | 显示或隐藏 CPU 段，段内显示使用率和 CPU 温度 |
| 显示指标 | 内存 | 开 / 关 | 开 | 显示或隐藏内存段，展示内存占用百分比 |
| 显示指标 | GPU（仅 NVIDIA） | 开 / 关 | 开 | 显示或隐藏 GPU 段，展示 GPU 使用率、显存占用和温度 |
| 显示指标 | 网络 | 开 / 关 | 开 | 显示或隐藏下载和上传速率 |
| 显示指标 | 时间 | 开 / 关 | 开 | 独立显示或隐藏本地时间 |
| 刷新率 | CPU / 内存 / 网络 | 1 秒、2 秒、5 秒 | 1 秒 | 设置这三类读数的刷新周期 |
| 刷新率 | GPU / 温度 | 3 秒、5 秒 | 3 秒 | 设置 GPU 和温度读数的刷新周期 |
| 外观 | 主题 | 跟随系统、深色、亮色 | 跟随系统 | 设置页和小窗按所选模式使用对应配色 |
| 外观 | 背景不透明度 | 20%–100%，每档 5 个百分点 | 96% | 只调整小窗背景，不降低文字不透明度 |
| 外观 | 字体大小 | 10–18 px，每档 1 px | 12 px | 调整小窗主字号；文字层级、卡片高度和部分间距随之变化 |
| 行为 | 开机自启 | 开 / 关 | 关 | 控制应用是否随系统启动；开发或预览环境中不可启用 |
| 行为 | 其他应用全屏时自动隐藏 | 开 / 关 | 开 | 其他应用全屏时收起小窗，离开全屏后按手动显隐状态决定是否恢复 |

设置项更改后自动保存并立即生效，无需单独点击“应用”。调整滑块时连续生效。保存成功后短暂显示“已保存”提示，约 2 秒后消失。

背景不透明度的旧默认值 72% 在设置加载时自动迁移为新默认 96%（72% 位于滑块 5 个百分点的步进网格之外，只可能来自旧默认而非用户手动选择）。

### 3.2 小窗与托盘共用菜单

小窗和托盘使用相同的右键菜单，菜单顺序如下：

| 顺序 | 菜单项 | 默认状态 | 规格 |
| --- | --- | --- | --- |
| 1 | 显示/隐藏小窗 | 显示 | 切换小窗显隐；托盘左键单击执行同一操作 |
| 2 | 打开设置 | — | 打开设置页 |
| 3 | 任务栏内水平居中 | 关闭 | 小窗停在顶部或底部任务栏行时，按整条任务栏行水平居中 |
| 4 | 透明显示 | 关闭 | 隐去小窗卡片装饰，保留文字和交互 |
| — | 分隔线 | — | 分隔退出操作 |
| 5 | 退出 | — | 结束应用 |

“任务栏内水平居中”和“透明显示”仅通过此菜单控制，不放入设置页。手动显隐优先于全屏自动隐藏：手动隐藏后，全屏状态不应重新显示小窗；手动显示后，全屏结束也不应自动将其收起。

## 4. 性能小窗规格

### 4.1 内容、顺序与读数格式

显示段顺序固定为 CPU、内存、GPU、网络、时间。用户关闭某一段后，其余段保持原顺序。分隔线仅出现在相邻可见段之间，不出现在小窗末尾。

| 段 | 标签 | 显示内容 | 格式与缺失状态 |
| --- | --- | --- | --- |
| CPU | CPU | CPU 使用率、CPU 温度 | 使用率为整数百分比；温度为整数加 °；缺失读数显示 -- |
| 内存 | 内存 | 内存占用百分比 | 整数百分比；缺失时显示 -- |
| GPU | GPU | GPU 使用率、显存占用百分比、GPU 温度 | 整数百分比和整数温度；缺失读数显示 -- |
| 网络 | 网络 | 下载与上传速率 | 下载前显示 ↓，上传前显示 ↑；单位 MB/s，保留 1 位小数；缺失读数显示 -- |
| 时间 | 无标签 | 本机本地时间 | 24 小时制 HH:mm:ss；独立于指标刷新，每秒更新 |

缺失读数及其单位使用弱化文字颜色；缺失时网络方向箭头也采用弱化色。时间使用等宽数字，避免数字更替时字符宽度变化。

### 4.2 位置、尺寸与贴边行为

| 项目 | 规格 |
| --- | --- |
| 形态 | 单行、横向胶囊形状态卡片；无标题栏；背景可透明 |
| 内容宽度 | 按可见内容自适应，最小宽度 64 px；内容变化不应造成明显的频繁横向闪动 |
| 卡片高度 | 随用户字号和实际文字高度变化；不得固定为一个与字号无关的高度 |
| 卡片左右内边距 | 各 7 px（透明显示 8 px） |
| 最大字样与卡片可视边框的间距 | 上下目标各 6 px；字号变化时尽量保持恒定 |
| 圆角 | 胶囊形：圆角为卡片高度的一半 |
| 段内容 | 只显示文字标签、读数、单位和网络上下行箭头；时间段只显示时间，不显示指标图标或保留图标占位 |
| 段悬停高光 | 鼠标悬停在某段上时，该段背景出现轻微高光 |
| 投影 | 四周环绕的高斯投影（html box-shadow 语义）：向下偏移 2 px、模糊 9 px；深色主题 alpha 0.32、亮色主题 0.16；投影完整落在 16 px 窗口留白内，不在窗口边缘截断 |
| 窗口留白 | 窗口矩形 = 卡片可视矩形四周各加 16 px 透明留白（投影空间）；命中区为卡片本身，留白不拦截鼠标；贴边、行内落位与水平居中均以卡片可视矩形为准 |
| 桌面位置 | 用户可拖动；位置和贴边状态在后续启动时沿用 |
| 贴边吸附 | 拖至可用工作区边缘 8 px 范围内时吸附；可同时吸附相邻边角 |
| 贴边后的可视关系 | 卡片可视边缘贴近屏幕/工作区边缘；保留约 1 px 的安全余量以免描边被裁切 |
| 任务栏行落点 | 松手时卡片中心位于顶部或底部任务栏行内，则卡片在该行内垂直居中（无需先满足贴边前提）；左右侧任务栏不提供此落点 |
| 任务栏行水平居中 | 开启后，卡片在任务栏行的全宽范围内水平居中，不绕开中部图标或通知区域；行内拖动松手后回到居中位置 |
| 行内位置恢复 | 关闭时卡片驻留任务栏行内，下次启动按当前任务栏几何落回行内垂直居中；行内水平居中开启时回到整行中心，否则沿用记录的水平位置（夹入行范围）；当前无任务栏行时回落普通贴边位置 |
| 置顶可见性 | 小窗位于任务栏行时应显示在任务栏之上；若被任务栏遮挡，应迅速恢复可见 |
| 全屏隐藏 | 启用时，其他应用全屏期间隐藏小窗；退出全屏后遵守用户最后一次手动显隐操作 |

“任务栏行”指显示器边界与可用工作区边界之间的水平带。行内水平居中的参照是整条任务栏行，不是托盘或任务栏图标组的位置。

### 4.3 字体与文字层级

| 文字角色 | 规格 |
| --- | --- |
| 字体偏好 | Segoe UI、Microsoft YaHei，最后回退到系统无衬线字体 |
| 主读数与时间 | 使用用户选择的主字号；字重约 600 |
| 指标标签 | 约为主字号的 82%，限制在 9–12 px；字重约 600 |
| 温度读数 | 主字号；字重约 400；° 与数字同行同尺寸 |
| 普通单位 | 约为主字号的 82%，限制在 8–12 px；字重约 400 |
| 网络方向箭头 | 主字号；字重约 500；使用各方向专属强调色 |
| 数字 | 使用等宽数字；不换行 |
| 垂直视觉对齐 | 不同字号的主体视觉中线彼此对齐；文字垂直居中 |
| 标签到首个读数 | 间距约为主字号的 0.58 倍 |
| 同段连续读数 | 间距约为主字号的 0.5 倍 |
| 数字到单位 | 约 1 px |
| 段间留白 | 分隔线所在区域宽度约为主字号的 0.83 倍 |

小窗的卡片高度、上下边距和文字垂直位置应共同满足“最大字样居中且上下留边相等”的视觉结果。改变主字号后，文字层级和相关间距应协调缩放。

### 4.4 小窗颜色

视觉基准为 `docs/UI/preview.html`；深色为主题原值，亮色为按对比度推导的对应值。

| 用途 | 深色主题 | 亮色主题 |
| --- | --- | --- |
| 卡片背景 RGB | 18, 21, 25 | 246, 247, 249 |
| 主文字、时间、网速数值、显存占用 | #f3f5f7 | #1a1d22 |
| 指标标签、单位 | #92979f | #5f656d |
| 温度 | #9da2a9 | #6a6f76 |
| 缺失读数 | 主文字 32% | 主文字 32% |
| CPU、内存、GPU 主占用读数 | #f3f5f7 | #1a1d22 |
| 下载方向箭头 | #27aaff | #1c7ed6 |
| 上传方向箭头 | #49dc8b | #0ca678 |
| 卡片细描边 | 白 10% | 黑 10% |
| 段间分隔线 | 白 13% | 黑 13% |
| 段悬停高光 | 白 2.5% | 黑 3% |

背景不透明度只作用于卡片背景。卡片不做顶部高光渐变或内顶高光装饰（html 中的对应效果在产品卡片尺度上不可感知，渲染出来反而像一条贴着文字的刻线）。投影为四周环绕的高斯投影（深色主题 alpha 0.32，亮色 0.16）。边框和分隔线保持细弱，不喧宾夺主。

开启“透明显示”后，卡片背景、描边、投影、段悬停高光和分隔线均不可见；指标名称、读数、单位、缺失占位、时间和网络方向字符继续显示。透明显示不改变拖动、右键菜单或命中区域。

## 5. 设置页规格

### 5.1 窗口和页面布局

| 项目 | 规格 |
| --- | --- |
| 标题 | 性能小窗 · 设置 |
| 宽度 | 固定 380 px |
| 高度 | 内容目标约 880 px；可用屏幕高度不足时随工作区缩小，但最低 560 px |
| 屏幕边缘留白 | 高度计算为工作区高度减约 48 px，再限制在 560–880 px 范围内 |
| 内容溢出 | 内容超出可用高度时出现低调滚动条 |
| 分组 | 显示指标、刷新率、外观、行为，按此顺序纵向排列 |
| 页面外边距 | 上 18 px、左右各 16 px、下 14 px |
| 正文 | 13 px；行高约为字号的 1.35 倍；字距约 -0.011em |
| 页面标题 | “设置”；21 px、字重约 700、行高约 1.1、字距约 -0.02em；标题区下方留 12 px |
| 保存提示 | “已保存”；12 px；出现约 2 秒后消失 |

设置页不能通过拖动边框任意缩放。可用高度不足时应保留页面滚动能力，不能裁掉“行为”分组。

### 5.2 分组卡片与控件

| 部件 | 规格 |
| --- | --- |
| 分组卡片 | 圆角 14 px；无明显边框和阴影；上内边距 2 px、左右 16 px、下 8 px；卡片间距 10 px |
| 分组标题 | 12 px、字重约 600、字距约 0.02em；上留白 10 px、下留白 4 px |
| 设置行 | 横向排列，标签与控件分居两侧；最小高度 32 px；两侧内容间距 12 px；上下内留白各 2 px |
| 行间分隔 | 约 0.5 px 的细线 |
| 开关 | 40 × 24 px，胶囊形；圆钮 20 × 20 px，距上/左各 2 px；开启时圆钮向右移动 16 px |
| 开关动画 | 背景和圆钮过渡约 0.2 秒 |
| 下拉框 | 12 px 字号；胶囊形、无明显描边；上下内边距 4 px、左 12 px、右 26 px |
| 下拉箭头 | 约 10 × 6 px；距右侧 9 px；描边约 1.6 px |
| 下拉悬停 | 亮度轻微降低至约 96% |
| 滑块 | 控件区域 130 × 24 px；轨道高 4 px；圆钮 18 × 18 px |
| 键盘焦点 | 2 px 强调色外框，外偏约 2 px |
| 滚动条 | 轨道区域宽 10 px；滑块内缩约 3 px，采用圆角细轨样式 |

设置行标签和控件均可直接操作。滑块拖动时连续生效。无需额外提交按钮。

## 6. 托盘规格

| 项目 | 规格 |
| --- | --- |
| 提示文字 | 性能小窗 |
| 左键操作 | 显示/隐藏小窗 |
| 右键操作 | 打开与小窗共用的菜单 |

## 7. 规格边界

本文件描述界面应呈现什么、用户可以怎样操作，以及关键视觉参数应达到的结果。实现可以采用不同的窗口、布局、绘制和持久化机制，但应保持本规格中的文案、选项范围、默认状态、配色、布局、显隐优先级和贴边/任务栏行为。
