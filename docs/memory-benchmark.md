# 内存配对测量方案（工票 15 / F13 / 验收 A43–A46）

状态：**方案成文（2026-10-05），所有实测结果留待人工执行；本文不含任何测量数字，相应结论一律标「未验证」。**

## 1. 测量口径（既定输入，不得更改）

- 指标：整棵 app 进程树的 **Private Bytes**（`Process.PrivateMemorySize64` 求和），MiB = 字节 ÷ 1024²（1048576）。
- 树的范围：根进程经 `Win32_Process.ParentProcessId` 递归的全部后代，**含短命 GPU 采样子进程**（nvidia-smi）、打开/隐藏的设置窗所属进程与 native 资源；每轮重建树，进程退出/新建即时反映。
- 不接受替代口径：工作集、安装包大小、单一进程名筛选、仅托管堆、历史旧版 107.2 MB 数值。
- 工具：`tools/memory-probe.ps1`（PowerShell 5.1 兼容；P95 用最近邻秩法，摘要中已注明方法）。

## 3. 环境与设置对齐（配对前提）

1. 同一台机器、同一次开机会话内完成新旧两侧全部轮次；中间不改硬件/驱动/后台负载。
2. 同权限：两侧都以同一种权限形态运行（建议都为普通权限，UAC 提示出现时统一批准或统一取消，并记录）。
3. 同设置：两侧统一刷新率（快 1000 ms、慢 3000 ms）、同指标开关组合（建议默认全开）、同主题与字号；设置值写入测量记录。
4. 采样期间不操作被测应用（静置），不进行前台重负载任务；网络流量、GPU 负载尽量保持日常背景水平。

## 4. 配对测量（验收 A43，≥3 轮）

### 轮次定义

每轮 = 冷启动 → 稳定期 → 采样期 → 退出：

1. **冷启动**：确认无该侧残留进程后启动应用。
2. **稳定期（静置 5 分钟）**：启动后不做任何操作，等待 5 分钟（启动抖动、JIT、首次采样建立基线）。
3. **采样期（5 分钟）**：以 1000 ms 间隔采样（约 300 样本）：

   ```
   powershell -ExecutionPolicy Bypass -File tools\memory-probe.ps1 `
       -ProcessName PerfMonitor.App -IntervalMs 1000 -DurationSeconds 300 `
       -WarmupRounds 0 -OutputCsv out\wpf-round<N>.csv
   ```

   旧版按其实际进程名替换 `-ProcessName`（或用 `-ProcessId`）。
4. **记录**：从探针摘要取稳定态均值 / P95（最近邻秩法）/ 峰值；同时记录 CPU 时间增量（任务管理器或 `Get-Process` 的 TotalProcessorTime）、启动到托盘可用的大致耗时、拖动手感主观备注。
5. **退出**：从应用菜单退出，确认进程树全部结束（含子进程）后进入下一轮。

≥3 轮配对：新 3 轮 + 旧 3 轮，交替进行（新-旧-新-旧-新-旧）以摊薄会话级漂移。

### 比较规则

对每轮独立计算均值 Mᵢ、P95ᵢ、峰值 Pᵢ，再取三轮的中位数（或均值，记录所用方法）作为该侧配对统计：

- **达标判据（规格 F13 硬约束）**：WPF 稳定态均值 **<** 旧版对应统计，WPF P95 **<** 旧版对应统计，WPF 峰值 **≤** 旧版对应统计。
- **噪声阈值**：|差异| < max(2 × 轮内样本标准差的最大值, 该侧均值的 2%) 时视为「在测量噪声内」。
- **补测规则**：任一统计落在噪声内 → 双侧各补测 1 轮（最多补 2 轮）；补测后仍无法区分 → 该项结论记「差异在测量噪声内，未验证」，**不得宣称达标**。

## 5. 压力验证（验收 A44）

### 5.1 一小时稳态

1. 冷启动后静置 5 分钟（稳定期，不计入统计）。
2. 以 10 s 间隔连续采样 1 小时（360 样本），`-WarmupRounds 30` 剔除前 5 分钟。
3. 判停标准：把样本按 10 分钟分段，若后段均值相对前段均值的抬升全部小于噪声阈值（同上），且 P95 无跨段单调抬升 → 通过；任一分段抬升超出噪声且下一分段未回落 → 判「内存平台持续抬升，未通过」。

### 5.2 50 轮设置开关

1. 冷启动，静置 5 分钟，采一轮基线（60 样本 @ 1 s）。
2. 循环 50 轮：打开设置窗 → 修改一项设置（轮换：刷新率 / 指标开关 / 主题 / 字号）→ 关闭设置窗 ≈ 1 轮；节奏约每轮 6 秒。
3. 结束后静置 10 分钟，再采 60 样本。
4. 判停标准：结束段稳定态均值相对基线抬升 < 噪声阈值，且静置段内无持续抬升（后 30 样本均值 ≤ 前 30 样本均值 + 噪声）→ 通过；否则判未通过。

### 5.3 20 轮隐藏/显示

1. 冷启动，静置 5 分钟，采一轮基线。
2. 循环 20 轮：托盘左键（或菜单）隐藏性能条 → 等待 5 秒 → 显示 ≈ 1 轮。
3. 结束后静置 10 分钟，再采 60 样本。
4. 判停标准：同 5.2。隐藏期样本会显示采样暂停的内存下降，属预期；统计只比较静置显示态。

### 5.4 诊断证据

压力验证未通过（或抬升接近噪声）时，用 dotnet-counters / dotnet-gcdump（托管堆）与 VMMap（native）取证，区分托管与 native 来源；证据文件与结论写入工票 15 Comments。
