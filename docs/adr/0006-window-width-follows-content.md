# 窗口宽度跟随内容自然宽

> 状态：Accepted

## 决策

- 性能条宿主窗口宽度跟随内容自然宽，可增可减，下限保留 64 DIP 命中区；高度继续由 SizeToContent 跟随。重复相同宽度不触发尺寸变化，也就不重摆窗口。
- 个位数读数保留等数字宽占位符（U+2007），9% 与 10% 同宽；宽度变化集中在位数增减边界（如 9.9→10.0、99→100），残余抖动频率低。
- 行内居中开启时，宽度变化立即按实际宽度重新居中，接受个位数字宽幅度的横向微移；不接受需要引入「居中时锁宽」特例，复杂度不值。
- 采样暂停（拖动/隐藏/修改刷新率）恢复时保留上一代已知读数：代际切换只更新代数戳，慢通道首轮发布并入旧值而不是把快通道字段置为缺失；否则松手或重新显示瞬间界面闪现 `--`，并连带一次宽度收缩。旧代际在途读数仍被既有代际隔离拒绝，不穿越到新快照。

## 依据

推翻「同一字号/指标开关组合下宽度只增不减（峰值宽）」的在案规则（本决策前 `.scratch/wpf-rewrite/spec.md` F06 与提交 41968d9 合入的峰值宽保留）：峰值宽以常驻留白换取零抖动，实际观察中网速等读数回落后卡片右侧长期空置。用户于 2026-10-05 确认：松手闪现 `--` 不可接受、宽度应跟随内容、直接跟随优于迟滞方案、接受行内居中的微移。自动化证据见 `PerformanceMetricsContractTests`「采样暂停恢复后，慢通道首轮发布保留快通道旧读数」；宽度跟随属视觉行为，列入验收矩阵 A18 人工复验。
