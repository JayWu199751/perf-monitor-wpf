# 性能小窗 v1.0.0

首个 GitHub 发布版本，适用于 Windows 11 x64。

## 功能

- CPU、内存、NVIDIA GPU、双向网络速度和时间显示。
- 简洁性能条、深浅主题、透明度、托盘菜单和开机自启。
- 全屏自动隐藏、位置吸附、设置窗闲置回收。
- 修复显示器 DPI 查询成功判断，正确处理缩放比例及设置窗最大高度。

## 安装

下载并运行 `PerfMonitorWpf-1.0.0-setup.exe`。此安装包依赖 **.NET Desktop Runtime 10.0（x64）**，需要事先安装运行时。

应用启动时会尝试请求管理员权限；拒绝后仍可运行，部分温度指标可能不可用。GPU 与温度读数取决于硬件和驱动支持。
