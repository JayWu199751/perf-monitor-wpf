# 可直接复制的完整启动提示词

复制以下分隔线后的全文；在新 WPF 仓库中使用，确保旁边有 `rewrite-wpf/` 文件夹。

---

请全程用中文，使用我安装的 Matt Pocock skills 帮我从零重写「性能小窗」。技术栈确定为 C# + WPF，运行目标 Windows 11 x64，原生 XAML 渲染。最终产品是常驻托盘的透明置顶单行性能条，而不是大型主界面。

本轮先完成启动核验、澄清真正的未决事项并形成可执行规格；不要在规格与分票尚未审阅前展开整仓实现。后续按已批准的票持续完成，不因单个文件完成就停止。

**新增硬约束：尽可能降低常驻内存。** 在完整功能、指标口径与交互体验保持的前提下，以整棵进程树Private Bytes作为选择方案与最终验收依据。必须做同机同配置旧版/WPF至少3轮配对测量：稳态均值和P95低于当前旧版、峰值不更高；差异落在噪声内补测，未达成或未测量就明确写「内存约束未满足/未验证」。不要使用历史107.2MB、工作集、包大小或「WPF天然省内存」代替证据。范围及压力验证由spec的F13和memory-budget.md定义。

## 完整产品要求摘要

- 普通启动只显示小窗与托盘；单实例，重复启动手动显示已有小窗；小窗无边框、无任务栏按钮、始终置顶；设置窗按需创建。
- 单行段顺序 CPU、内存、GPU、网络、时间。CPU 使用率及 ACPI 热区温度；内存占比；NVIDIA GPU 利用率、专用显存占比、温度；网速下行/上行；本地 `HH:mm:ss` 独立秒级更新。百分比和温度整数，网速一位小数，缺失值 `--` 而非 0。
- CPU 读累计时间差分；内存用未取整物理字节算百分比；网络进程内 `GetIfTable2Ex` 读取 64 位计数：up 且非 loopback，优先 PhysicalMediumType 非 Unspecified，完全没有物理候选才退回全集；取收发之和最大的一行，不求和、不分别取上下行最大。按实际单调时间差和 `1024²` 换算，首轮为 0、回退计数为 0、新网卡重建基线。暂停恢复重建基线。
- GPU 保持 NVIDIA-only，无控制台异步 nvidia-smi，5 秒超时；多行选择首条有效设备并明确记录，失败不影响 CPU/内存/网络。CPU 温度进程内 WMI，非管理员/无 ACPI/访问失败降级为 `--`，不引入常驻 PowerShell。
- 默认快刷新 1 秒（选项 1/2/5），慢刷新 3 秒（选项 3/5）；快慢独立、无同通道重叠；停止与重启隔离旧异步任务。小窗隐藏暂停采样，显示立即补采样；拖动暂停采样/投递，松手只投递最新并补采样。
- 整条小窗可原生拖动；8 DIP 内贴工作区四边/四角，透明外边距推出使可视卡片贴边并保留安全边框；向屏幕内拖离阈值解除。500ms 防抖保存真实落点，退出 flush；创建期/同步移动重入不能覆盖恢复位置。
- 多显示器正确定位，负坐标、混合 DPI、插拔与工作区变化后可恢复；只维护一份最后位置，逐屏位置档案并非本轮既定功能。
- 用户可把同一张卡拖入顶部/底部水平任务栏行，卡片中心在行内时垂直居中；行矩形是显示器边界与工作区之差，左右任务栏不支持行内。默认横向自由；共享菜单「任务栏内水平居中」开启后拖动跟手、松手回全行水平中心，关闭原地保留。覆盖处会拦截点击，沿用已确认代价。
- 行内点击任务栏切应用后不能永久消失；真机验证 WPF 的 z-order，不把 Topmost 当作证据。若需要守卫，参考旧 30ms 快检测、300ms 慢刷新句柄与行内状态，悬浮态早退、隐藏停止、explorer 重启恢复。不要照抄 Electron 档位名。
- 全屏自动隐藏默认开，约每秒检查前台窗口；排除本 app 与系统桌面/任务栏窗口；普通最大化不等于全屏，F11 无边框全屏必须识别，统一物理坐标。只在状态边沿响应，手动隐藏优先，自动隐藏期间手动显示后同一全屏周期保持显示，下一轮全屏重新自动隐藏；关闭自动隐藏时只恢复自动原因隐藏的小窗。
- 托盘左键显隐；托盘与小窗右键共享命令真值，菜单依次「显示/隐藏小窗」「打开设置」「任务栏内水平居中」「透明显示」、分隔、「退出」。两项勾选只在菜单出现，并持久化；透明显示只去掉背景/描边/阴影/分隔线，文字和命中区域保留，不能做鼠标穿透。
- 保留三柱 app 图标与明暗托盘图标，随有效主题/DPI 更新；explorer 重启后重新注册托盘。没有黑窗闪烁。
- 设置四组：指标五开关、快慢刷新、主题/背景不透明度/字号、开机自启/全屏自动隐藏。默认指标全开、system 主题、背景不透明度 72%、字号 12 DIP、自启关、行内居中关、透明显示关。背景 20–100% 滑块步长 5%，字号 10–18；文字不随背景一起变透明。
- 随改随保存、两秒「已保存」、菜单与设置同步。中央 Settings 真值；指标补丁深合并；位置 controller 独占；JSON 校验、缺键补全、损坏备份和原子写。新配置目录与旧 app 隔离，明确导入才迁移。
- 设置窗关闭隐藏，5 分钟闲置释放、重开取消回收，窗口高度适应内容与当前屏工作区，短屏可滚动访问所有行；退出/关机/注销不被隐藏拦截。
- Debug 普通权限无 UAC；Release 有管理员运行路径和 CPU 温度真机验证。澄清 requireAdministrator 与「拒绝后当前进程降级」的冲突；建议 asInvoker + 一次 runas 及尝试标志。处理提权实例交接，避免重复弹窗/双开。
- 自启用当前用户 ONLOGON 最高权限计划任务，正确处理带空格路径，失败回写真实关状态，Debug 不改系统配置；新任务名隔离，明确迁移才清理旧任务/Run 项。
- 发布可运行 win-x64 Release 产物，包含图标、配置/权限说明、测试与真机验收记录；无遥测、云功能或自动更新。
- 内存必须尽可能低：轻量依赖、按需创建、有限缓存、及时释放native/图形/WMI资源；只变化的数据刷新UI、复用可复用度量/Brush，隐藏/退出不留周期采样子进程。做1小时稳态、50轮设置开关、20轮隐藏/显示，排除持续增长；优化不能砍功能，不能靠每秒强制GC掩盖泄漏。

## 视觉要求

保持紧凑、单行、深浅两主题、主读数与次级读数层级、蓝色网速箭头和等宽数字；按 HTML 原型与 design 文件落实 XAML。

卡片高度由最大字号主读数/时钟真实墨迹派生，上下到可视边框各 6 DIP；不能用固定 22/26/38 像素高伪造。混合字号按主体中线共线，`°` 对齐最大字样 cap 线并保持缺失态稳定；设置窗不使用性能条校正。WPF 需要自己的像素量具和字体测量，不能复制 Chromium 系数。宿主窗口宽度跟随卡片内容自然宽，可增可减；个位数读数用等数字宽占位符防抖（见 docs/adr/0006），卡片内部内容自然宽允许呼吸。

旧 ADR-0006 存在 125% 下边距失败的记录；新实现必须报告真实矩阵，不声称继承旧「全绿」。浏览器样图也不能当作 WPF 的 DPI、alpha 或任务栏验收。

## 工程与技能执行

- 先检查工作目录、本机 SDK、技能路径、依赖兼容性；版本按已安装/受支持稳定 SDK 确定并锁定。
- 使用 `/ask-matt` 选择流程；必要时在目标 repo `/setup-matt-pocock-skills` 配置 tracker 与 domain docs。按 repo 的 CONTEXT.md 布局保留领域术语。
- `/grill-with-docs` 只问材料不能回答的产品取舍。已给出的功能和默认值直接作为输入。
- 用 `/to-spec` 合成正式规格，与我核对最高层测试接缝；用 `/to-tickets` 审阅 `rewrite-wpf/tickets/` 草案，确定纵向切片和真实阻塞关系后发布到 `.scratch/wpf-rewrite/issues/`，每票一个文件。
- 每票 `/implement`，用 `/tdd` 做用户可观察行为的红绿切片，结尾 `/code-review` 对照标准与规格。无需用大量镜像 XAML 属性的测试代替行为验证。
- 若我明确选择 `/implement-spec`，按技能的已批准任务图编排。没有选择该流程时按阻塞完成顺序逐票推进。
- 纯规则/状态机不引用 WPF/Win32；native adapter 只做映射和资源管理；UI 只绑定快照/命令；组合根负责连接。优先简单的 3 个生产项目，避免每个类都抽接口。
- `acceptance.md` 的每项都给出证据；自动化、Windows integration、人工验收分开记录。不可用的硬件/权限测试写「未验证」并提供复验步骤。
- 资源按整棵 app 进程树私有内存、CPU 单核占比和子进程占空比测量；普通工作集不作为省内存结论。先测再说，不承诺未经测量的 WPF 内存数字。
- 在相同功能的候选方案间比较Private Bytes；避免引入WebView、完整UI套件、通用Host/DI/遥测管线等本工具用不到的常驻设施。发布压缩、单文件、关闭GPU加速是否省内存必须各自测量。为满足F13持续优化并保存前后证据。
- 更新实际 build/test/publish 命令与进度记录；每阶段报告完成项、验证结果和剩余阻塞。
