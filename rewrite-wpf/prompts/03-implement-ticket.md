# 单票实现提示词

复制时替换 `<本票路径>`。实际正式票应位于目标 repo tracker；`rewrite-wpf/tickets/` 只是分票输入。

---

/implement

请全程中文完成 `<本票路径>`，先读本repo AGENTS.md、正式spec与本票所有blocked-by；行为依据 `rewrite-wpf/spec.md`，验收依据 `rewrite-wpf/acceptance.md`，视觉依据 `rewrite-wpf/ui/design.md` 和 HTML 原型。

1. 检查现有代码与相关历史测试，列出本票的可观察完成条件及需要实际桌面的条件。阻塞票未完成时处理真实依赖，不伪造已完成。
2. 用 `/tdd` 从最高合适的行为接缝做一个红绿切片，再扩大。controller纯规则与native adapter分开，XAML绑定真值；避免只测试实现细节。
3. 完整打通本票数据→规则→窗口/界面→持久化（如适用），完成可演示的纵向行为。时钟/数据/OS端口注入只为合同所需，不为每个类添加通用接口。
4. 运行项目实际build/test命令。改文字/字体/字号/布局跑WPF像素矩阵；改窗口/透明/z-order跑原生桌面探针；改提权/自启跑普通与管理员两种入口。HTML截图不能替代这些检查。
5. 进行 `/code-review` 的Standards + Spec评审并修复有效问题。没有硬件/权限时记录未验证和复验命令，不宣称通过。
   常驻对象/缓存/native资源/后台任务变更必须满足F13：阅读memory-budget.md，说明生命周期和上限，记录本票前后的整树Private Bytes；选择相同功能更低内存方案，不能靠周期强制GC或删功能压数字。
6. 更新本票验收checkbox、证据、构建/测试命令和接续建议。报告结果与剩余限制。票未完成不能仅凭代码存在就标done。

范围守卫：保持NVIDIA-only、物理网卡取同一行最大、手动显隐优先、任务栏覆盖式落点、菜单独占两开关、动态墨迹卡高和单份位置。需改变合同先给具体证据并记录决定。
