# UI 设计与 WPF 映射

设计问题：完整功能如何放进一条安静的性能条，并让设置仍能快速操作？原型选择单行条和独立设置窗；所有场景操控属于外部展示工具。

## 设计方向

2026-10-06 起性能条视觉语言以 `docs/UI/preview.html` 为基准（A49）：深蓝灰胶囊形卡片、每段线性描边图标、彩色主读数（CPU 绿 / 内存蓝 / GPU 绿）与双向网络箭头色、段悬停高光、四周环绕投影。亮色主题为按对比度推导的对应值；字号、间距与窗口高度体系维持原规格，显存读数保留（白色次级读数）。设置为窄列分组表单，不引入侧导航、大数字仪表板或图表，不受本次改版影响。

| --- | --- | --- | --- |

字体：Segoe UI，中文 Microsoft YaHei；数字 tabular-nums；主读数/标签/时间字重 600，温度与单位 400，箭头 500。横向节奏：数字单位 1DIP、伴随读数 0.50fs、标签到首读数 0.58fs、图标到标签 0.75fs、段分隔 0.83fs；图标边长 1.12fs。圆角为胶囊形（卡片高一半）。没有定宽数字槽。正式卡高=最大字号主读数/时钟墨迹高+上下 6DIP 到可视框，安全边框另计。

HTML为近似视觉参考：使用浏览器inline排版和示例位移，不是WPF文字拟合表。设置字体与性能条的光学度量分离。正式实现按 `acceptance.md` 验证主体中线、居中、边距、上标、裁切。

## 页面与交互

`index.html` 双击即用、无依赖、无网络请求、无持久化。支持URL参数 `?theme=dark&scene=taskbar`，scene为float/dock/taskbar/fullscreen，theme为system/dark/light。参数未知时回默认。

- 五开关：同步增删条内段及分隔线，全部关闭保留最小命中区域。
- 主题：跟随系统/深/亮，同时更新性能条、设置窗、菜单与托盘图标。
- 字号/背景滑块：预览立即变化，背景变化不淡化文字；有示例「已保存」反馈。
- 刷新选择与行为开关：更新原型状态，不调用OS计划任务或采样系统。
- 场景按钮：浮动、贴边、任务栏行内、全屏；全屏场景按照手动/自动优先级隐藏。退出全屏能恢复自动隐藏；关闭自动隐藏仅恢复自动隐藏状态。
- 示例数据：正常、高负载、不可用；只有时间在可见状态每秒更新，数值为固定夹具。
- 鼠标拖动：在模拟桌面中自由拖动，支持边缘/底部任务栏落点。UI提供四边结果示意，不证明多DPI Win32行为。
- 左键模拟托盘图标：显隐；小窗/托盘右键或「右键菜单」按钮打开共享菜单。
- 菜单两checkbox立即作用且互相同步；透明显示去掉非文字元素，仍保留命中区。
- 设置窗X隐藏，打开设置可恢复；5分钟回收只在规格中定义，原型不运行原生窗口回收。
- 退出为停止本页面演示，可按「重置演示」恢复；不会关闭浏览器或杀进程。
- 「查看原型状态」「导出示例配置」便于讨论，明确属于工具；导出是用户主动触发的下载，默认不写localStorage。

## 控件映射

| HTML原型对象 | WPF候选 | 约束 |
| --- | --- | --- |
| 单行性能条 | 定制文本绘制/Inline/Run + Border | 共线与cap线按像素校准，不能靠固定高包住 |
| 桌面中的窗口位置 | Window + HwndSource adapter | 实际native矩形，per-monitor DPI转换 |
| 五开关/行为开关 | ToggleButton/CheckBox样式 | 真值来自Settings，菜单专用字段不在设置窗出现 |
| 滑块 | Slider + 数值TextBlock | 20–100%、10–18，键盘支持 |
| 刷新/主题 | ComboBox | 明确选项，无自由数值误输入 |
| 设置分组 | StackPanel/Grid + 标题和细线 | 实际工作区不足才用ScrollViewer兜底 |
| 共享菜单 | 一份命令模型映射ContextMenu与托盘菜单 | 不必同一个native菜单对象，状态和动作必须同源 |
| 托盘图标 | NotifyIcon或Shell_NotifyIcon adapter | DPI HICON与明暗主题，explorer重建 |

CSS的backdrop-filter仅表达目标观感。WPF透明/背板方案由ticket02真机探针定；在资料和验收中说明结果，不把网页磨砂当成原生已实现。

## 检查设计

保留单行数据条为唯一性能展示，设置四组不添加重复仪表盘；去掉冗余装饰。数字字体、网速单位、上标温度与开关具有实际信息含义。原型响应式布局、keyboard focus、菜单Esc关闭、减少动态效果；产品最终仍按Windows桌面尺寸验收。
